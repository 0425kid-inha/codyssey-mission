# 로우폴리 3D 어항 커스터마이징 시뮬레이터 기획서

## 1. 프로젝트 개요

- **프로젝트명(가칭):** 나만의 작은 어항
- **목표:** 아늑한 3D 방의 선반에 어항 하나를 설치하고, 생물과 외관을 꾸민 뒤 두 가지 고정 시점에서 감상하는 웹 시뮬레이터를 만든다.
- **핵심 경험:** 복잡한 사육 관리가 아닌 **선택 → 즉시 반영 → 감상**의 흐름.
- **표현 방식:** 스타일라이즈드 로우폴리 3D. 생물은 단순한 형태와 반복 애니메이션으로 구현한다.
- **기술:** HTML, CSS, JavaScript, Three.js. 첫 버전은 단일 HTML 파일을 기준으로 하되 Three.js 라이브러리는 CDN에서 불러올 수 있다.
- **저장:** 브라우저 `localStorage`를 이용한 자동 저장. 서버와 로그인 기능은 없다.

## 2. 공간 및 기본 장면

방은 고정된 3D 장면으로 구성한다.

- 책상, 컴퓨터 모니터, 의자, **어항 전용 선반**, 창문과 닫힌 암막커튼, 실내 조명을 배치한다.
- 선반에는 **어항 설치 공간이 정확히 한 자리**만 있다. 어항 둘을 동시에 설치할 수 없다.
- 창문은 항상 암막커튼으로 닫혀 있고 외부 햇빛·가로등 등 외부광은 고려하지 않는다.
- 어항이 없는 상태에도 방과 빈 선반은 보인다.
- 방 전체 시점에서 선반 위 어항이 잘 보이도록 구도를 잡는다. 주변 가구는 어항을 가리지 않는다.
- 가구, 방의 구조, 커튼 위치는 첫 버전에서 변경할 수 없다.

## 3. 카메라와 화면 전환

사용자에게 노출되는 시점은 **2개**이며, 자유 회전·궤도 이동 기능은 제공하지 않는다.

1. **방 전체 시점:** 방의 책상·컴퓨터·의자·선반과 어항이 함께 보이는 고정 구도.
2. **어항 정면 시점:** 설치된 어항의 정면을 가까이서 바라보는 고정 구도. 생물과 장식품 감상에 충분한 크기로 표시한다.

- 버튼으로 시점을 전환하며, 카메라 위치와 시선 방향을 **부드럽게 보간**해 이동·확대한다. 즉시 화면이 바뀌는 컷 전환은 사용하지 않는다.
- 이동 중 중복 버튼 입력은 최종 목표 시점으로 자연스럽게 이어지도록 처리한다.
- 어항이 없을 때는 방 전체 시점이 기본이다. 어항 정면 버튼은 비활성화한다.
- 페이지 새로고침 시 카메라는 방 전체 시점에서 시작해도 된다. 카메라 시점을 저장할 필요는 없다.

## 4. 어항 선택 및 교체 규칙

처음에는 선반이 비어 있고, 사용자는 다음 중 **하나**를 선택해 설치한다.

- **담수 어항:** 구피·새우 혼합, 바닥재 및 장식품 커스터마이징.
- **해파리 어항:** 해파리 전용, 수조 형태와 조명 스타일 커스터마이징.

**배타적 선택:** 한 어항이 설치된 상태에서는 다른 유형을 추가할 수 없다. 유형을 바꾸려면 먼저 **어항 초기화**를 실행해 선반을 비운 뒤 새로 선택한다.

**초기화:** 확인 절차를 거쳐 현재 어항 유형·생물·바닥재·장식품·해파리 조명 등 어항 관련 설정을 삭제하고 선반을 비운다. 방 조명 설정은 유지한다. 초기화 직후에는 어항 선택 UI로 돌아간다. 이 동작은 localStorage에도 즉시 반영한다.

## 5. 담수 어항

### 5.1 수조 형태

- **기본 사각형 수조**
- **큐브형 수조**

두 형태 모두 같은 선반 위치를 사용하고, 정면 시점에서 내부를 볼 수 있도록 투명한 전면을 구현한다. 수조 형태를 바꿔도 기존 생물·바닥재·장식품 선택은 유지한다.

### 5.2 바닥재 (필수 단일 선택)

- **밝은 모래** — 연한 베이지 또는 아이보리
- **검은 자갈** — 어두운 회흑색
- **갈색 소일** — 짙은 갈색

바닥재는 **항상 정확히 한 종류**가 적용된다. 선택하면 수조 바닥 전체의 재질/색상이 즉시 바뀐다. 기본값은 밝은 모래다. 바닥재를 아예 없애는 선택지는 첫 버전에 포함하지 않는다.

### 5.3 장식품 (독립 ON/OFF)

- **수초**
- **돌**
- **유목**
- **작은 은신처**

장식품 규칙:

- 각 장식품은 독립된 체크박스/토글로 표시 여부를 바꾼다.
- 각 종류는 **0개 또는 1개**만 둘 수 있다. 같은 종류를 여러 번 추가할 수 없다.
- **모두 OFF(0개)부터 모두 ON(4개)**까지 모든 조합을 허용한다.
- 장식품마다 서로 다른 **고정 배치 좌표**를 부여한다. 사용자가 위치를 끌어서 바꾸지는 않는다.
- 장식품을 모두 켜도 서로 겹치지 않도록 좌표와 모델 크기를 설계한다. 사각형/큐브형 양쪽에서 확인한다.
- ON/OFF 변경이 즉시 3D 장면에 반영되며, 선택 상태는 자동 저장된다.

### 5.4 조명

- 담수 어항에는 **항상 켜진 고정 흰색 조명**이 포함된다.
- 담수 어항 조명 색상이나 ON/OFF를 사용자가 바꾸는 기능은 없다.
- 방 조명 OFF 상태에서도 담수 어항 조명은 켜진다.

### 5.5 생물

- **구피 4종:** 레드, 블루, 옐로, 모자이크(로우폴리 모델의 색/꼬리 무늬 차이로 구분).
- **미니 새우 4종:** 체리, 블루드림, 옐로, 스노우볼(색상 차이로 구분).
- 구피와 새우를 **자유롭게 혼합**할 수 있다.
- 같은 바리에이션을 여러 마리 추가할 수 있다.
- 모든 바리에이션을 합쳐 **최대 5마리**로 제한한다. 최소 0마리도 허용한다.
- 각 개체를 목록에서 구별해 **1마리씩 제거**할 수 있다.

움직임:

- 구피는 수조의 중·상층에서 천천히 이동하고 가끔 방향을 바꾸며 꼬리를 좌우로 흔든다.
- 새우는 바닥 근처에서 느리게 기어가거나 잠시 멈춘다. 수초·장식품과의 정밀 충돌/상호작용은 구현하지 않는다.
- 모든 생물은 수조 경계를 벗어나지 않으며, 수조 크기가 바뀌어도 내부에 머문다.

## 6. 해파리 어항

### 6.1 수조 형태

- **원통형 수조**
- **둥근 모서리형 수조**

두 종류 모두 해파리를 감상하기 좋은 투명한 전용 수조로 표현한다.

### 6.2 조명 커스터마이징

- **블루 / 퍼플 / 민트 / 핑크 / 화이트** 중 1개 선택.
- 선택한 조명이 수조 내부와 해파리에 반영되며, 가능하면 주변 선반에도 은은하게 비친다.
- 해파리 어항의 조명은 **항상 켜짐**으로 설정한다. 별도 OFF 기능은 없다.
- 방 조명 ON/OFF와 독립적으로 동작한다.

### 6.3 해파리 바리에이션 및 움직임

- 서로 구분되는 **로우폴리 해파리 3종**을 제공한다. 예: 기본 반구형, 작은 종형, 넓은 우산형. 색감은 선택한 어항 조명에도 영향을 받는다.
- 같은 바리에이션을 여러 마리 추가할 수 있고, 서로 다른 종류를 혼합할 수 있다.
- **해파리 전체 합계 최대 5마리**, 최소 0마리. 개별 제거 가능.
- 해파리는 수조 내부에서 느리게 부유하고, 몸체를 주기적으로 수축·팽창하며 짧은 촉수를 부드럽게 흔든다.
- 해파리 어항에는 구피와 새우를 넣을 수 없다.
- **바닥재와 장식품은 제공하지 않는다.** 실제 사육 조건을 참고해 내부를 비워 둔다.

> 주의: 해파리의 세 가지 바리에이션은 첫 버전에서 시각적 구분을 위한 디자인 분류이며, 실제 합사 가능한 세 가지 생물학적 종이라고 주장하지 않는다. 앱은 사육 지침이 아닌 꾸미기 시뮬레이터다.

## 7. 전체 방 조명

- **방 조명 ON/OFF** 토글을 제공한다.
- ON: 따뜻한 색상의 실내 조명이 방·책상·의자·선반을 비춘다.
- OFF: 실내 조명 광원을 끄거나 강도를 낮춰 방이 확연히 어두워진다.
- 어항 조명은 방 조명과 **완전히 독립**적이다. 방의 불을 꺼도 담수 어항의 흰 조명, 해파리 어항의 선택한 색 조명은 유지된다.
- OFF 상태에서 어항 빛으로 어항과 선반 일부가 은은하게 보이게 한다. 장면 전체가 완전한 검은 화면이 되지 않도록 최소한의 시각적 가독성은 유지하되, 외부 자연광을 표현하지 않는다.
- 구현은 단순한 검은색 화면 오버레이가 아니라 Three.js 광원의 밝기/활성 상태 변화로 처리한다.
- 방 조명 상태는 **localStorage에 저장**하고 새로고침 후 복원한다.

## 8. UI 구조와 조작 흐름

**데스크톱 우선 레이아웃:** 넓은 3D 렌더링 영역과 오른쪽의 커스터마이징 패널로 구성한다. 화면 크기가 작으면 패널은 접거나 아래로 이동해 조작 가능하게 한다.

상시 컨트롤:

- `방 전체` / `어항 정면` 시점 버튼
- `방 조명 ON/OFF` 버튼
- 현재 어항 유형 표시
- `어항 초기화` 버튼(어항이 있을 때)

어항이 없을 때:

1. 빈 선반과 방을 보여준다.
2. 패널에서 `담수 어항 설치` 또는 `해파리 어항 설치` 중 하나를 고른다.
3. 선택한 어항을 선반에 생성한다.
4. 유형에 맞는 커스터마이징 메뉴를 연다.

담수 어항 패널:

- `수조 형태` 선택
- `바닥재` 단일 선택
- `장식품` 4종 독립 체크박스
- `생물` 구피/새우 종류별 추가 버튼, 현재 마릿수 `n/5`, 개별 제거 목록
- 담수 조명은 `흰색 · 고정` 상태로만 표시하며 변경 컨트롤은 제공하지 않는다.

해파리 어항 패널:

- `수조 형태` 선택
- `조명 색상` 단일 선택
- `해파리` 바리에이션별 추가 버튼, 현재 마릿수 `n/5`, 개별 제거 목록
- 바닥재/장식품 메뉴는 표시하지 않는다.

생물 5마리 상태에서는 추가 버튼을 비활성화하거나 클릭 시 한도 안내를 보여준다. 제거 후 다시 추가 가능하다. 모든 변경은 별도 저장 버튼 없이 즉시 반영한다.

## 9. 3D 표현 및 기술 설계

- Three.js의 기본 메시(박스, 원기둥, 구, 원뿔, 구면 일부 등)를 조합해 로우폴리 방·가구·수조·생물을 만든다.
- 생물별 위치·회전·크기·간단한 관절/몸체 변형을 애니메이션 루프에서 갱신한다.
- 투명 수조 벽과 물은 반투명 재질로 표현하되 내부 생물을 가리지 않도록 한다.
- 카메라는 목표 위치 및 바라보는 지점을 보간해 2개의 고정 구도 사이만 이동한다.
- 어항마다 카메라의 정면 목표 위치를 조정해 두 수조 형태가 모두 적절히 프레이밍되도록 한다.
- 방 광원과 어항 광원을 분리해 실내 조명을 끄더라도 어항이 밝게 보이도록 한다.
- 생물 수 제한은 UI에서만이 아니라 상태 변경 로직에서도 검증한다.
- 정밀 물리, 수질, 먹이, 번식, 수명, 생물 간 포식과 질병 시뮬레이션은 구현하지 않는다.

## 10. 상태와 localStorage 저장

저장해야 할 상태:

```json
{
  "version": 1,
  "roomLightOn": true,
  "aquarium": {
    "type": "freshwater",
    "tankShape": "rectangle",
    "substrate": "lightSand",
    "decorations": {
      "plants": true,
      "rocks": false,
      "driftwood": false,
      "hideout": false
    },
    "lightColor": "white",
    "creatures": [
      { "id": "unique-id-1", "kind": "guppy", "variant": "red" },
      { "id": "unique-id-2", "kind": "shrimp", "variant": "cherry" }
    ]
  }
}
```

- `aquarium`은 어항이 없을 때 `null`이다.
- 해파리 유형에서는 바닥재·장식품을 적용하지 않으며, 해파리 수조 형태/조명 색/해파리 개체를 저장한다.
- 초기 생성 시 합리적인 기본값을 적용한다: 담수는 사각형·밝은 모래·흰 조명·장식 0개·생물 0마리, 해파리는 원통형·블루 조명·생물 0마리.
- 사용자의 모든 설정 변경 후 즉시 localStorage를 갱신한다.
- 재접속/새로고침 시 마지막 유효 설정을 복원한다.
- 손상된 저장 데이터나 범위를 벗어난 값은 안전한 기본값으로 대체한다. 저장된 생물이 5마리를 초과하면 최대 5마리까지만 로드한다.
- 생물의 정확한 위치/애니메이션 진행 상태는 저장하지 않으며 복원 시 새로 배치한다.

## 11. 완성 기준 (검수 체크리스트)

- [ ] 페이지를 열면 책상, 컴퓨터, 의자, 암막커튼, 선반을 포함한 로우폴리 3D 방이 보인다.
- [ ] 선반에는 어항을 하나만 설치할 수 있다. 담수와 해파리 어항을 동시에 둘 수 없다.
- [ ] 어항 설치 전에는 선반이 비어 있고 두 어항 유형 중 하나를 고를 수 있다.
- [ ] 방 전체 시점과 어항 정면 시점만 있으며, 버튼을 누르면 카메라가 부드럽게 이동한다.
- [ ] 담수 수조 2종과 해파리 수조 2종의 형태가 화면에서 구별된다.
- [ ] 담수 바닥재 3종이 단일 선택으로 작동하고 바닥 색상이 바뀐다.
- [ ] 담수 장식품 4종이 각각 ON/OFF 되고, 0~4개 모든 조합이 가능하며 중복 생성이나 겹침이 없다.
- [ ] 담수에는 구피 4종과 새우 4종을 혼합해 넣을 수 있다.
- [ ] 해파리 수조에는 해파리 3종만 넣을 수 있고 바닥재/장식품 메뉴가 없다.
- [ ] 생물은 종류와 관계없이 수조당 최대 5마리이며, 개별 추가·제거가 된다.
- [ ] 구피는 헤엄치고, 새우는 바닥을 이동하고, 해파리는 부유하는 단순한 애니메이션이 보인다.
- [ ] 생물이 수조 경계 밖으로 나가지 않는다.
- [ ] 담수 조명은 흰색으로 고정되고, 해파리 조명은 5색 중 하나를 고를 수 있다.
- [ ] 방 조명 OFF 시 방은 어두워지고 어항 조명은 켜진 상태로 남는다. 외부광 표현은 없다.
- [ ] 모든 커스터마이징 설정과 방 조명 상태가 localStorage에 자동 저장되고 새로고침 후 복원된다.
- [ ] 어항 초기화 시 확인 후 선반이 비워지고 어항 설정은 삭제되지만 방 조명 상태는 유지된다.
- [ ] 별도 서버 없이 브라우저에서 실행할 수 있으며, 일반적인 데스크톱 화면에서 UI 조작이 가능하다.

## 12. 첫 버전 제외 범위

- 자유 카메라 회전 및 자유 배치/드래그
- 방 구조나 가구 커스터마이징
- 먹이, 수질, 성장, 번식, 생존, 경제·구매 시스템
- 장식품의 종류별 중복 배치
- 해파리와 담수 생물의 혼합
- 수중 물리 시뮬레이션 및 사실적 고품질 생물 애니메이션
- 계정, 클라우드 저장, 다중 어항 및 공유 기능

**핵심 원칙:** 선반 한 자리에 하나의 어항을 설치하고, 간단한 선택만으로 꾸민 뒤, 조명과 두 시점을 바꿔 가며 편안하게 감상한다.
