# 나만의 작은 어항 — 로우폴리 3D 어항 커스터마이징 시뮬레이터

## 대상 사용자

- 실제 어항을 설치하거나 생물을 기르지 않고도 가상의 어항을 꾸미고 감상하고 싶은 사람.
- 복잡한 사육 관리보다는 간단한 조작으로 아늑한 3D 공간을 만들고 싶은 사람.
- 데스크톱 브라우저를 주로 사용하는 사람.

## 사용 목적

- 가상의 방 안 선반에 **담수 어항 또는 해파리 어항 하나**를 설치하고, 수조·생물·장식·조명을 취향에 맞게 꾸민다.
- 사용자의 선택을 3D 화면에 즉시 반영하고, 방 전체와 어항 정면의 두 시점에서 감상한다.
- 설정을 브라우저에 자동 저장해 다음에 열었을 때도 꾸민 상태를 유지한다.
- 핵심 사용 흐름은 **어항 선택 → 커스터마이징 → 시점과 조명 변경 → 감상**이다.

## 화면 구성과 동작

- **화면 배치:** 넓은 3D 렌더링 영역과 오른쪽 설정 패널로 구성한다. 화면이 좁으면 패널을 접거나 아래로 배치해 조작할 수 있게 한다.
- **3D 방:** 책상, 모니터, 의자, 어항 전용 선반, 창문, 닫힌 암막커튼, 실내 조명을 표시한다. 선반에는 어항을 놓을 수 있는 자리가 하나뿐이다. 커튼은 열리지 않으며 외부광은 표현하지 않는다.
- **초기 화면:** 어항이 없는 빈 선반을 보여 주고 `담수 어항 설치`와 `해파리 어항 설치` 버튼을 제공한다. 선택한 유형 하나만 설치할 수 있다.
- **상시 조작:** `방 전체` / `어항 정면` 버튼으로 두 고정 시점을 부드러운 카메라 이동으로 전환한다. 어항이 없으면 정면 시점은 비활성화한다. `방 조명 ON/OFF`로 방의 광원을 변경하되 어항 조명은 유지한다.
- **담수 어항 패널:** 사각형·큐브형 수조, 바닥재 3종, 장식품 4종의 표시 여부, 구피·미니 새우의 추가·제거를 조작한다. 흰색 어항 조명은 항상 켜진다.
- **해파리 어항 패널:** 원통형·둥근 모서리형 수조, 조명 색상 5종, 해파리의 추가·제거를 조작한다. 바닥재·장식품 메뉴는 없다.
- **마릿수 및 초기화:** 각 어항의 생물은 모두 합쳐 최대 5마리까지 추가할 수 있고 개별 제거할 수 있다. `어항 초기화`는 확인 후 어항과 관련 설정만 삭제하며, 방 조명 설정은 유지한다. 다른 유형으로 교체하려면 먼저 초기화한다.
- **저장:** 모든 변경은 즉시 화면에 반영되고 `localStorage`에 자동 저장된다. 새로고침 시 마지막 유효 설정을 복원한다. 카메라 시점과 생물의 순간 위치는 저장하지 않아도 된다.

## 필요한 자료

- **개발 기술:** HTML, CSS, JavaScript, Three.js(필요 시 CDN 로드), 브라우저 `localStorage`.
- **3D 오브젝트:** 책상·모니터·의자·선반·암막커튼과 방, 담수 수조 2종, 해파리 수조 2종, 바닥재·장식품·생물의 로우폴리 모델. Three.js 기본 도형을 조합해 직접 표현한다.
- **담수 바닥재 3종:** 밝은 모래(기본값), 검은 자갈, 갈색 소일. 한 번에 정확히 하나만 선택한다.
- **담수 장식품 4종:** 수초, 돌, 유목, 작은 은신처. 종류별로 0개 또는 1개만 표시하고 각각 겹치지 않는 고정 위치에 배치한다. 모두 끄거나 모두 켤 수 있다.
- **담수 생물 8종:** 구피 4종(레드·블루·옐로·모자이크), 미니 새우 4종(체리·블루드림·옐로·스노우볼). 구피와 새우의 혼합 및 같은 종류의 여러 마리 추가를 허용한다.
- **해파리 생물 3종:** 기본 반구형, 작은 종형, 넓은 우산형의 시각적 디자인 구분. 같은 디자인의 여러 마리나 서로 다른 디자인의 혼합을 허용한다.
- **조명:** 담수 어항의 고정 흰색 조명, 해파리 어항의 블루·퍼플·민트·핑크·화이트 단일 선택 조명, 따뜻한 색의 방 조명.
- **애니메이션:** 구피의 유영 및 꼬리 움직임, 새우의 바닥 이동, 해파리의 부유·수축·팽창·촉수 움직임을 단순 반복 애니메이션으로 표현한다.

## 필수 기능

1. **어항 단일 설치·초기화:** 빈 선반에 담수 또는 해파리 어항을 하나만 설치하고, 확인 후 초기화할 수 있다.
2. **수조 종류별 꾸미기:** 담수 수조 2종·바닥재 3종·장식품 4종, 해파리 수조 2종·조명 색상 5종을 선택 즉시 반영한다. 담수의 흰색 조명은 고정한다.
3. **생물 추가·제거:** 담수는 구피와 새우를 섞을 수 있고 해파리는 해파리만 넣을 수 있다. 개체별로 추가·제거하며 종류와 관계없이 최대 5마리로 제한한다.
4. **3D 감상:** 생물의 간단한 움직임을 표시하고 수조 밖으로 나가지 않게 하며, 방 전체/어항 정면 두 시점을 부드럽게 전환한다.
5. **방 조명 제어:** 방 조명은 켜고 끌 수 있으며 어항 조명은 방 조명과 독립적으로 계속 켜진다.
6. **자동 저장 및 복원:** 어항 설정과 방 조명을 `localStorage`에 저장해 새로고침 후 복원한다. 잘못된 저장값은 기본값으로 대체하고 5마리 제한도 재검사한다.

## 완료 기준

- [ ] HTML 페이지에서 책상·모니터·의자·암막커튼·선반이 있는 로우폴리 3D 방이 표시된다.
- [ ] 선반이 비어 있는 상태에서 두 어항 중 하나를 설치할 수 있으며, 두 개를 동시에 설치할 수 없다.
- [ ] `방 전체`와 `어항 정면` 시점 사이를 버튼으로 부드럽게 이동한다. 어항이 없으면 정면 시점은 사용할 수 없다.
- [ ] 담수 수조 2종 및 해파리 수조 2종의 외형 차이가 표시된다.
- [ ] 담수 바닥재는 3종 중 하나만 적용되며, 장식품 4종은 각각 독립적으로 켜고 끌 수 있다. 장식품을 모두 켜도 중복 생성·겹침이 없다.
- [ ] 담수에는 구피 4종·새우 4종을 섞어 넣을 수 있고, 해파리 어항에는 해파리 3종만 넣을 수 있다.
- [ ] 생물은 총 0~5마리만 존재하고 개별 제거가 가능하며, 수조 안에서 종류에 맞는 단순한 움직임을 보인다.
- [ ] 담수 어항은 고정된 흰색 조명, 해파리 어항은 선택 가능한 5색 조명을 가진다.
- [ ] 방 조명을 끄면 방은 어두워지지만 어항 조명은 켜져 있고, 창문 밖 외부광은 표현되지 않는다.
- [ ] 새로고침 후 어항 유형·수조·바닥재·장식·생물·조명 설정이 복원된다.
- [ ] 초기화하면 어항만 사라지고 방 조명 상태는 유지되며, 초기화 상태도 저장된다.
- [ ] 계정이나 별도 서버 없이 브라우저에서 실행된다. 단, Three.js 실행을 위해 인터넷 연결이 필요하다.

## 추가 기능

- **작은 화면 대응:** 설정 패널을 접거나 화면 아래로 내려 화면 폭이 좁아도 주요 버튼을 조작할 수 있게 한다.
- **시점 전환 중 추가 입력 대응:** 카메라 이동 중 다른 시점 버튼을 눌러도 마지막으로 선택한 목표 시점까지 자연스럽게 이동하게 한다.
- **저장 데이터 오류 처리:** 저장 데이터의 구조·종류·수량을 확인하고 잘못된 값이 있으면 유효한 기본 상태로 복원한다.
- **은은한 조명 연출:** 방 불을 끄면 어항과 주변 선반 일부만 조명으로 은은하게 보이도록 한다.

## 한계 및 비목표

1. **실제 사육 시뮬레이션이 아님:** 먹이·수질·성장·번식·질병·수명·포식 및 정밀 물리 연산은 구현하지 않는다. 해파리 3종은 시각적 디자인 구분이지 실제 합사 가능한 생물종을 뜻하지 않는다.
2. **자유 배치·공간 편집을 제공하지 않음:** 방 구조·가구·커튼은 고정되고, 카메라 자유 회전 및 장식품 드래그 이동·중복 배치는 지원하지 않는다.
3. **온라인·다중 어항 기능을 제공하지 않음:** 한 번에 어항 하나만 설치할 수 있으며 로그인, 계정 연동, 서버·클라우드 저장, 다른 사용자와 공유 기능은 구현하지 않는다. 저장 데이터는 현재 브라우저의 로컬 환경에만 남는다.

## 검증 방법

- **수동 시나리오 테스트:** 브라우저에서 빈 선반 → 담수 어항 설치 → 바닥재 3종 변경 → 장식품 4종 모두 ON/OFF → 구피·새우 합계 5마리 추가 → 6번째 추가 시도 → 1마리 제거 → 시점과 방 조명 변경 → 새로고침 → 초기화 → 해파리 어항 설치 → 조명 5색 변경 및 해파리 5마리 추가 순서로 직접 조작한다. 각 단계의 **화면 결과와 마릿수·선택값을 완료 기준과 비교**하고, 새로고침 전후 설정이 일치하는지 확인한다. 생물이 수조 경계 밖으로 나가지 않는지도 두 시점에서 관찰한다.
