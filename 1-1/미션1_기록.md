네이토에게 등급 구성, 영화 카드 이동 방식, 데이터 저장 방식, 공유 방식에 대해 물어봤다.
영화 카드 이동 방식은 드래그 앤 드롭과 클릭/선택 방식을 모두 만들어 달라고 했고, 데이터 저장은 로컬 스토리지로 브라우저에 저장, 공유 방식은 처음엔 이미지 저장으로 만들려고 했다.

여기서 받은 기획서를 "기획서.md"라고 저장했고, 이를 토대로 "영화_A_수정.html"을 생성하였다.

분명 처음에 네이토는 "- **클릭/선택:** 영화를 클릭하고 등급을 선택하면 해당 칸으로 이동하는 방식 (구현이 상대적으로 쉬움)"라고 언급하였는데, "기획서.md" 를 나중에 확인해보니 영화 카드의 클릭 이동 방식은 어느새 순환 이동으로 바뀌어 있었다.

그런줄도 모르고 코드 작성 과정에서 문제가 있었다고 생각했고. 어떻게 영화 카드가 움직이고 있는지도 직접 테스트를 하며 찾아냈다. 처음부터 기획서.md를 받자마자 내 요구사항이 정확히 들어갔는지 꼼꼼히 점검하는 것이 좋았을 것 같다.

이 점을 찾아내지 못해 영화_A_수정을 새로 만들었지만, 사실 기획서 상으로는 영화_ A_초안이 맞았다.
