# 🎬 영화 티어리스트(Movie Tier List) 기획서 (v2)

## 1. 누가 쓰나 (Target Audience)

- **영화 애호가:** 자신이 본 영화를 등급별로 정리하고 기록하고 싶은 사람.
- **데이터 관리형 사용자:** 작성한 티어리스트를 텍스트(JSON) 데이터로 소장하거나 나중에 다시 불러오고 싶은 사람.

## 2. 무엇을 하려고 (Purpose)

- **시각적 분류:** 영화들을 S, A, B, C 등급으로 나누어 한눈에 파악할 수 있게 함.
- **데이터 보존:** 브라우저의 `LocalStorage`를 활용해 재방문 시에도 데이터 유지.
- **데이터 내보내기:** 현재의 티어 상태를 JSON 파일로 다운로드하여 데이터 형태로 보관.

## 3. 화면과 동작 (UI & Interactions)

### 🖼 화면 구성

- **입력부:** 영화 제목 입력창과 '추가' 버튼.
- **티어 영역:** S, A, B, C 등급별 행(Row). 각 행은 고유 색상의 라벨을 가짐.
- **미분류 영역:** 추가된 영화 카드가 최초로 생성되는 대기 장소.
- **하단 버튼:** 'JSON으로 저장하기' 버튼.

### ⚙️ 주요 동작

- **영화 추가:** 제목 입력 후 엔터 키 또는 버튼 클릭 시 '미분류' 영역에 카드 생성.
- **영화 이동 (2-Way):**
    1. **드래그 앤 드롭:** 마우스로 카드를 끌어서 원하는 등급 칸/미분류 칸으로 자유롭게 이동.
    2. **클릭 이동:** 카드 클릭 시 다음 등급으로 자동 순환 (미분류 → S → A → B → C → 미분류).
- **가변 UI & 반응형:**
    - 영화 카드가 많아지면 등급 칸의 높이가 유연하게 늘어남 (Flexbox 활용).
    - 화면 너비가 좁아지면 카드가 자동으로 다음 줄로 넘어감 (Wrap).
- **카드 디테일:**
    - **말줄임표:** 카드 너비를 벗어나는 긴 제목은 `...`으로 생략.
    - **툴팁:** 카드에 마우스를 올리면 브라우저 기본 툴팁(`title` 속성)으로 전체 제목 표시.

## 4. 필요한 자료 (Resources)

- **초기 영화 데이터:**
    - 기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리.
- **기술 스택:**
    - **HTML5 / CSS3:** 가변 레이아웃(Flexbox) 및 카드 디자인.
    - **Vanilla JavaScript:** 드래그 앤 드롭 API, 클릭 이벤트, LocalStorage 활용, JSON Blob 생성 및 다운로드 로직.
- **외부 라이브러리 사용 안 함:** 순수 코드로만 구현하여 가볍고 독립적인 구조 유지.

## 5. 완성 기준 (Definition of Done)

1. **동작성:** 영화 추가 및 두 가지 방식(드래그/클릭)의 이동 기능이 완벽히 작동한다.
2. **지속성:** 새로고침 시에도 `LocalStorage`에서 데이터를 읽어와 이전 상태를 복구한다.
3. **가변성:** 영화 카드 개수나 창 크기에 따라 레이아웃이 깨지지 않고 유연하게 변한다.
4. **데이터 저장:** 'JSON으로 저장' 버튼 클릭 시, 현재 티어 정보가 포함된 `.json` 파일이 정상적으로 다운로드된다.
