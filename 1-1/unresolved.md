# 미해결 문제 기록

## 1. 불필요한 추가 정보 요구

### 문제 설명

고객 문의에 답변하기 위해 직접적으로 필요하지 않은 정보를 추가로 요구하는 문제가 발생하였다.

### 사용한 프롬프트

실버 회원입니다. 회원 할인율과 골드 회원으로 승급하기 위해 필요한 정확한 구매 금액을 함께 알려주세요.

### 해결 시도

시스템 프롬프트 v1에서 불필요한 추가 질문을 제한하고, v2에서는 판단 결과의 분류 기준과 추가 확인 사항의 작성 조건을 명확하게 정의하였다.

### 실행 결과

시스템 프롬프트 v2 적용 이후에도 다음과 같은 추가 확인 사항이 생성되었다.

> 담당 부서를 통한 골드 회원 승급 기준 구매 금액 및 실적 산정 기간 확인, 고객의 정확한 결제일(2026년 11월 1일 규정 시행 전후 여부) 및 기존 구매 실적 확인

회원 승급에 필요한 일반적인 구매 금액 기준을 문의하였으므로 고객의 정확한 결제일과 기존 구매 실적을 확인할 필요는 없다고 판단하였다.

### 해결하지 못한 이유

추가 정보가 필요한 상황에 대한 기준을 설정하였으나, 각각의 정보가 고객 문의의 해결에 직접적으로 필요한지를 판단하는 구체적인 기준까지 정의하지 않았기 때문이라고 판단하였다.

### 최종 상태

미해결

## 2. 출력 서식의 일관성 부족

### 문제 설명

시스템 프롬프트에서 네 가지 필수 출력 항목을 지정하였으나, 각 항목의 구분과 줄바꿈이 일관되게 유지되지 않는 문제가 발생하였다.

### 사용한 프롬프트

서울에 거주하는 골드 회원입니다. 행사 대상이 아닌 55,000원짜리 일반 키보드를 구매하면서 회원 할인과 적립금 5,000원을 사용하려고 합니다. 최종 결제 금액과 배송비, 구매 적립금은 각각 얼마인가요?

### 해결 시도

시스템 프롬프트 v2에 다음 규칙을 추가하였다.

> 모든 고객 문의에 예외 없이 다음 네 가지 출력 항목을 사용한다.
>
> 판단 결과:
> 고객 응대 메시지:
> 판단 근거:
> 추가 확인 사항:
>
> 판단 근거에는 반드시 관련 규정의 조항 번호를 명시한다. 추가 확인 사항이 없다면 '없음'으로 작성한다.

### 실행 결과

시스템 프롬프트 v2 적용 이후 네 가지 필수 출력 항목은 모두 생성되었으나, 다음과 같이 항목 사이의 구분이 명확하지 않은 응답이 생성되었다.

> 판단 결과: 정보 제공 고객 응대 메시지: 안녕하세요, 고객님. NOVA STORE 고객센터입니다.

필수 항목의 누락 문제는 개선되었으나 세부적인 출력 서식의 일관성은 확보하지 못하였다.

### 해결하지 못한 이유

필수 출력 항목의 존재 여부만 강조하였으며, 항목별 줄바꿈과 구분 방식까지 구체적으로 강제하지 않았기 때문이라고 판단하였다.

또한 자연어 프롬프트만으로 출력 구조를 완전히 통제하는 데에는 한계가 있다고 판단하였다.

### 최종 상태

부분 개선, 미해결

## 3. 미해결 문제 종합

| 문제 | 해결 시도 | 최종 상태 |
|---|---|---|
| 불필요한 추가 정보 요구 | 판단 기준 및 추가 확인 조건 보완 | 미해결 |
| 출력 서식의 일관성 부족 | 필수 출력 항목 및 작성 조건 강화 | 부분 개선, 미해결 |

두 문제 모두 시스템 프롬프트 v2 적용 이후에도 남아 있는 문제이며, 추가적인 개선 실험은 진행하지 않았다.
