# 모델 비교

## 1. 과업 정의

### 과업명

상점 운영 규정 기반 고객 문의 응답 생성

### 업무 문제

온라인 상점의 고객센터에서는 배송, 할인, 반품, 교환, 보증 등에 관한 반복적인 문의를 처리해야 한다. 운영 규정이 복잡해질수록 담당자가 관련 조항을 찾고 예외 조건을 판단하는 데 많은 시간이 소요된다.

본 과업에서는 가상의 온라인 상점 NOVA STORE를 대상으로, LLM이 운영 규정을 참조하여 정확하고 일관된 고객 문의 답변을 생성하도록 한다.

### 타겟 사용자

NOVA STORE의 고객센터 상담 담당자.

### 입력 데이터

- NOVA STORE 고객 서비스 운영 규정 v1.0
- 고객의 문의 내용
- 필요한 경우 상품 유형, 구매 날짜, 회원 등급 등의 추가 정보

### 출력 규격

1. 판단 결과: 가능, 불가능, 확인 필요, 정보 제공 중 하나
2. 고객 응대 메시지: 고객에게 전달할 답변
3. 근거: 판단에 사용한 운영 규정의 조항
4. 추가 확인 사항: 판단에 필요한 정보가 부족한 경우 작성

| 출력 형식 준수 | GPT는 요청하지 않은 최종 요약을 추가하였으며, Claude는 추가 확인 사항에 불필요한 설명을 포함함. Gemini는 지정된 형식을 간결하게 유지함. |

## 4. 모델별 세부 평가

### GPT-5.6 Luna

- 답변이 장황하며 불필요한 조항을 인용하거나 필요한 조항을 누락하는 경우가 있음.
- 문의 1: 별도의 보증 기간이 명시되지 않았다는 정보를 제공했음에도 재확인을 요청함.
- 문의 5: 상품이 리퍼비시 제품인지 확인하는 절차가 누락됨.

### Gemini Hydrogen

- 답변이 간결하며 불필요한 조항 참조가 적음.
- 판단에 필요한 정보를 적절하게 선별하여 확인함.
- 문의 5: 보증 기간을 정확하게 설명하였으나 해당 수치의 근거인 제21조를 인용하지 않음.

### Claude Haiku 5.5

- 답변이 비교적 간결하나 불필요한 조항을 인용하는 경우가 있음.
- 문의 2: 고객이 골드 회원임을 밝혔음에도 결제 시점의 회원 등급을 재확인하도록 안내함.
- 문의 3: 단순 변심에 의한 반품임을 밝혔음에도 상품의 기능상 결함 여부를 추가로 확인함.

## 5. 최종 모델 선정

**선정 모델: Gemini Hydrogen**

**선정 근거:** 세 모델 모두 핵심 판단의 정확성에서는 차이가 없었으나, Gemini Hydrogen은 답변이 간결하고 불필요한 조항 참조 및 추가 확인 요청이 적었으므로 최종 모델로 선정하였다.
