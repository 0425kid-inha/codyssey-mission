### 내가 발견한 문제점
화면 폭이 좁아지면 오른쪽이 그대로 잘림

중복된 제목의 영화도 추가할 수 있음. 제목이 공백인 영화도 추가 가능.
파일을 다시 열면 정보가 사라짐

'처음으로'를 누르면 기존에 있던 것 외에 추가한 영화들이 모두 사라짐. 기획서 상 내용을 보면 의도한건지 모호

### 민수님의 입장

| 받은 의견 | 직접 해 본 결과 | 반영/보류/되묻기 | 이유 |
| 저장 기능이 없음 | 실제로 저장이 안됨| 반영 | 기획서에도 나와있는 기능이니 정상적으로 동작하도록 수정하기로 결정 |
| '처음으로'가 정상동작하지 않음 | 피드백과는 달리 추가된 영화카드가 그대로 남는게 아니라 사라지는 것을 확인. | 보류 | 기획서에는 '처음 영화 8개가 모두 미분류로 돌아갑니다'라고 정했음. 이후에 추가한 영화들은 사라지는게 기획상으로 맞음.
| 빈 제목으로도 영화가 생성됨. 중복 제목으로도 영화를 추가할 수 있음. | 실제로 오류 존재 | 반영 | '제목을 입력하면' 새 영화 카드가 생긴다고 기획서에 명시했으므로 빈 제목으로 카드를 추가하는 현상은 수정. 기획서에서 짚지 못한 내용이지만, 같은 제목의 카드가 여러개 존재하는 것은 어색한 동작으로 판단. 기획과 다른 내용은 아니었지만, 마찬가지로 수정하기로 결정 |
| 휴대폰으로 열어보니까 좀 불편했어요. | 어떤 부분이 불편한지 알 수 없음 | 되묻기 | 정확히 어떤 부분이 불편했는지 자세히 알려주시겠어요? |
| 카드 옮기는게 헷갈리고 불편했어요 | 의도한 대로 동작하고 있었음 | 보류 | 기획서와 애초 의도한 대로 카드가 잘 동작함. 영화 목록의 위치도 아래에 있는게 취향에 맞음 |
| 카드 색이 칙칙한 느낌 | 카드가 회색으로 통일됨 | 보류 | 등급에 색이 있으니 카드는 차분한 색으로 통일하는 것이 취향에 맞음 |
| 영화 포스터 사진이 같이 나오게 | 영화 카드에는 제목만 나타나고 있음 | 보류 | 깔끔한 ui를 원해서, 포스터 이미지가 들어가면 정신없을 것 같음 |
| C칸은 굳이 없어도 될 것 같아요 | 애초에 좋아하는 영화들을 추가해서 쓰다보니 실제로 C칸에 넣을 영화가 거의 없음 | 반영 | 실제 사용경험상으로도 C칸이 큰 의미가 없다는걸 깨달음 | 
| 창 크기를 줄였을 때 화면 잘림 | 어느정도 이상 줄이면 요소가 줄어드는게 아니라 그대로 잘리는걸 확인 | 반영 | 기획서에도 잘리지 않는다고 명시하였으므로 수정해야 함 |
