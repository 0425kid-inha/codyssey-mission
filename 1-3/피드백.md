# 민수의 영화 티어리스트 피드백

## 잘된 점
- 영화를 S·A·B·C 등급으로 분류하고, 미분류 영화 목록을 따로 확인할 수 있도록 구성한 점이 좋았습니다.
- 영화 카드를 선택한 뒤 등급을 누르거나 드래그 앤 드롭으로 이동할 수 있어 조작 방법이 다양합니다.
- 영화 제목을 입력해 목록에 새 카드를 추가할 수 있습니다.

## 고치면 좋을 점
1. 좁은 화면에서 오른쪽 내용이 잘림
- 본 것: 브라우저 창의 너비를 줄였더니 화면 오른쪽 내용이 잘려 보였습니다.
- 기준: 기획서의 완성 기준인 '화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다.'
- 제안: 화면 너비에 맞춰 레이아웃이 줄어들도록 수정하고, 좁은 화면에서는 입력창과 버튼 등도 자연스럽게 줄바꿈되면 좋겠습니다.

2. 중복된 제목의 영화를 추가할 수 있음
- 본 것: 이미 목록에 있는 영화와 같은 제목을 입력해도 새 영화 카드가 추가되었습니다.s
- 기준: 기획서에 중복 제목 처리에 관한 조건은 없습니다. 다만 같은 영화를 여러 번 분류하게 될 수 있어 사용 중 혼란스럽습니다.
- 제안: 이미 등록된 제목이라면 추가를 막고 안내 메시지를 보여 주면 좋겠습니다. 서로 다른 영화가 제목이 같을 수 있다는 점까지 고려한다면, 중복을 허용할지 확인하는 방식도 가능합니다.

3. 공백인 제목의 영화를 추가할 수 있음
- 본 것: 제목을 입력하지 않거나 공백만 입력한 뒤 '추가'를 누르면 제목이 없는 영화 카드가 생성되었습니다.
- 기준: 기획서에 빈 제목 처리 조건은 없지만, 제목을 입력해 영화 카드를 추가하는 기능의 취지에 맞지 않습니다.
- 제안: 앞뒤 공백을 제거한 뒤 제목이 비어 있으면 카드를 생성하지 않고 '영화 제목을 입력해 주세요.'라는 안내를 표시하면 좋겠습니다.

4. 파일을 다시 열면 영화와 등급 정보가 사라짐
- 본 것: 영화를 추가하거나 등급을 변경한 뒤 HTML 파일을 닫았다가 다시 열면 이전 변경 사항이 사라지고 초기 상태로 돌아갔습니다.
- 기준: 기획서의 완성 기준인 '같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다.'
- 제안: 영화 목록과 등급 정보를 브라우저의 로컬 저장소(localStorage 등)에 저장하고, 파일을 다시 열 때 복원하도록 수정하면 좋겠습니다.

5. '처음으로' 버튼을 누르면 추가한 영화가 모두 사라짐
- 본 것: 새 영화를 추가한 다음 '처음으로'를 누르니, 직접 추가한 영화가 사라지고 기본 영화 8개만 남았습니다.
- 기준: 기획서에는 '처음 영화 목록과 배치로 돌아갑니다.'라고 되어 있고, 완성 기준에는 '처음 영화 8개가 모두 미분류로 돌아갑니다.'라고 적혀 있습니다. 따라서 현재 동작은 기획 의도에 부합할 수 있지만, 추가한 영화까지 삭제할지 여부는 명확하게 설명되어 있지 않습니다.
- 제안: 버튼이 전체 목록을 초기화하는 기능이라면 '전체 초기화'처럼 이름을 명확히 하고, 추가한 영화가 삭제된다는 확인창을 제공하면 좋겠습니다. 등급만 초기화하려는 목적이라면 직접 추가한 카드도 미분류 영역으로 되돌리는게 자연스러울 것 같습니다.
